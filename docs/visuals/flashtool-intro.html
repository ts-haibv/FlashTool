Vấn đề hiện tại

Vì sao cần FlashTool?

01 / PLATFORM
Chỉ hỗ trợ Windows
Flash tool do Sharp cung cấp hiện tại chỉ chạy trên Windows. Các máy dùng Linux không cài được — QA/dev trên Ubuntu phải mượn máy Windows hoặc tự chạy lệnh tay.
02 / PHÂN MẢNH
Mỗi model một app
Mỗi model device (PS11, E11, E10, E9, G6…) lại có một app flash riêng biệt. Người dùng phải cài và chuyển qua lại giữa nhiều tool khác nhau.
03 / QUY TRÌNH
Flash Jenkins phức tạp
Muốn flash ROM build Jenkins phải tải cả ROM Jenkins lẫn ROM Official, rồi copy đè file Jenkins vào gói Official trước khi flash — thủ công, dễ nhầm file.

Giải pháp

Một app cho tất cả

  • Cross-platform: chạy trên cả Windows và Ubuntu/Linux — build sẵn thành executable, không cần cài Python
  • Một app duy nhất cho mọi model: G6 / X6 / X5 / X5P, PS10, PS11, E11, E10, E9
  • GUI hiện đại (CustomTkinter, dark theme) thay cho terminal và nhiều tool rời rạc
  • Flash Jenkins trực tiếp: chỉ cần chọn folder ROM Jenkins — tool tự detect Official/Jenkins, không cần copy đè thủ công

Automation

Chọn folder — tool lo phần còn lại

  • Auto-detect model từ nội dung folder ROM: signature file + variant directory (scoring, chọn match tốt nhất)
  • Auto-detect variant (MC6, Kira, ML2…) từ thư mục con hoặc tên file system_ext-*
  • Auto-detect ROM type Official / Jenkins — hoặc override thủ công qua dropdown
  • Auto-resolve image theo partition: system.img, product-*.img, vbmeta*.img… không cần chỉ tay từng file

G6 / X6 / X5 / X5P

13 bước adb / fastboot

  • Unlock bootloader + verify
  • Flash vbmeta (disable verification)
  • Reboot → chờ ADB → vào fastbootd
  • Flash system / product / system_ext
  • Erase metadata + userdata, reboot

PS11 / E11 / E10 / E9

Script + phase tracking

  • Validate package & vào bootloader
  • Flash bootstrap → vào fastbootd
  • Flash dynamic partitions (super)
  • Flash bootloader / modem / vbmeta
  • Set active slot, wipe, reboot

Mỗi phase của script được map thành step card riêng trên UI — nhìn thấy script đang chạy đến đâu.

Trải nghiệm & an toàn

Kiểm soát toàn bộ quá trình

  • Device polling 3s: trạng thái adb / fastboot / disconnected hiển thị real-time
  • Bootloader helper: reboot to bootloader, check unlock status (ro.boot.flash.locked, getvar unlocked), nút unlock riêng có xác nhận
  • Progress từng step: progress bar + elapsed time, parse cả sparse-image upload từ fastboot
  • Console log live + nút Cancel ở mọi bước
  • Skip Setup Wizard: mark provisioned qua ADB, reboot — bỏ qua màn hình setup đầu tiên
